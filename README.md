### Часть 1. Теория

**1. Пять основных блоков видеокарты:**
1.  **GPU (Графический процессор):** Главный вычислительный чип, выполняющий расчёты графики и параллельные задачи.
2.  **VRAM (Видеопамять):** Быстрая буферная память для хранения текстур, кадров и промежуточных данных GPU.
3.  **Шина памяти:** Канал передачи данных между GPU и VRAM влияет на пропускную способность.
4.  **Подсистема питания:** Преобразует и стабилизирует напряжение для GPU и памяти VRM.
5.  **Система охлаждения:** Радиаторы и вентиляторы для отвода тепла от нагревающихся компонентов.

**2. Отличия GPU от CPU:**
*   **Архитектура:** CPU имеет несколько мощных ядер с сложным управлением, GPU — тысячи простых ядер.
*   **Задачи:** CPU выгоден для логики, ветвлений, ОС и баз данных. GPU выгоден для рендеринга графики, обработки изображений и матричных вычислений, где одну операцию нужно применить к огромному массиву данных одновременно.

**3. VRAM и её отличие от ОЗУ:**
VRAM — это память, расположенная на самой видеокарте. Она отличается от системной ОЗУ тем, что физически ближе к GPU и имеет сверхширокую шину. Видеопамять делают максимально быстрой, потому что GPU приходится постоянно перекачивать гигантские объёмы текстур и геометрии; если память будет медленной, мощный чип будет простаивать в ожидании данных.

**4. SIMT и варпы:**
SIMT (Single Instruction, Multiple Threads) — это принцип, при котором одна инструкция выполняется сразу группой потоков. GPU группирует потоки в «варпы» (обычно по 32 штуки), чтобы один блок управления мог эффективно командовать ими. Если потоки в варпе делают одно и то же (например, красят пиксели), эффективность максимальна; если они «разбегаются» по разным веткам кода, часть ядер простаивает.

**5. Охлаждение и питание:**
Подсистема питания нужна для подачи стабильного тока нужной силы (особенно при разгоне). Охлаждение необходимо, так как КПД GPU не 100%, и часть энергии уходит в тепло. Если охлаждение не справится, сработает троттлинг (сброс частот), что резко снизит производительность, а в худшем случае — перегрев и выход из строя.

### Часть 3. Практика

**7. Характеристики твоей видеокарты (из nvidia-smi + спецификации):**
*   **Модель:** NVIDIA GeForce GT 1030
*   **Объём VRAM:** 2048 MiB (2 ГБ) 
*   **Тип памяти:** GDDR5 (судя по пропускной способности и частым версиям, это GDDR5; у DDR4 версии пропускная способность была бы всего 16 ГБ/с) 
*   **Ширина шины:** 64 бит 
*   **Число ядер (CUDA):** 384 
*   **TDP:** 30 Вт 

**8. Расчёт пропускной способности памяти:**
Формула: `Частота памяти (МГц) × Ширина шины (бит) / 8`.
У GT 1030 (GDDR5) эффективная частота памяти составляет 6000 МГц (или 1502 МГц реальная, но в формуле используется эффективная для получения ГБ/с, либо реальная с множителем, но проще взять паспортную эффективную).

*   *Расчёт:* `6000 МГц × 64 бит / 8 = 48 000 МБ/с = 48 ГБ/с`.
*   *Сравнение:* Паспортное значение для GDDR5 версии — **48 ГБ/с** . Результат совпадает. (Примечание: в некоторых утилитах мониторинга может показываться реальная частота 1502 МГц, но эффективная скорость передачи данных в 4 раза выше).

**9. По шагам от «запустить игру» до картинки:**
1.  **CPU:** Получает команду, загружает данные игры с диска в системную ОЗУ, обрабатывает логику (ИИ, физику) и формирует список команд (draw calls) для отрисовки.
2.  **PCI-E:** CPU отправляет эти команды и необходимые данные (геометрию, текстуры) через шину PCI-E в видеокарту.
3.  **VRAM:** Видеокарта принимает данные и загружает текстуры и буферы в видеопамять.
4.  **GPU:** Получив команды, GPU запускает тысячи потоков (шейдеров), которые читают данные из VRAM, вычисляют цвет каждого пикселя и преобразуют 3D-модели в 2D-изображение.
5.  **Вывод:** Готовый кадр записывается в буфер кадра и через разъём (HDMI) отправляется на монитор, который отображает его на экране.

### Часть 4. Вывод

Видеокарты стали нужны для ИИ, потому что нейросети по своей сути являются набором огромных матричных и векторных операций, которые нужно выполнять параллельно над миллионами чисел. Архитектура GPU SIMT изначально создавалась для того, чтобы независимо обрабатывать миллионы пикселей, что идеально подходит для параллельных вычислений в ИИ. Если CPU — это мощный математик, решающий сложную задачу шаг за шагом, то GPU — это армия простых рабочих, которые могут одновременно перемножить миллионы чисел, что даёт колоссальный выигрыш в скорости обучения моделей.
