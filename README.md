## 1. DDR
DDR — *Double Data Rate*.  
Тип оперативной памяти, в которой данные передаются дважды за такт — по переднему и заднему фронту тактового сигнала. Это удваивает пропускную способность по сравнению с обычной SDR-памятью. Современные поколения: DDR4, DDR5.

## 2. DIMM
DIMM — *Dual In-line Memory Module*.  
Это форм-фактор модуля оперативной памяти: печатная плата с контактами с обеих сторон, независимыми друг от друга. Используется в настольных ПК и серверах.

## 3. Ранг — что это?
Ранг — это группа микросхем памяти на модуле, которые работают совместно и обслуживаются одним сигналом выбора чипа (CS).  
Один ранг выдаёт за такт 64 бита данных (для обычной памяти). Модуль может быть одноранговым (1R), двухранговым (2R) и т.д. Больше рангов — больше ёмкость, но выше нагрузка на контроллер памяти и возможны ограничения по частоте.

## 4. CAS Latency
CAS Latency — задержка строба адреса столбца.  
Показывает, сколько тактов памяти проходит между запросом на чтение данных и их фактической выдачей из массива. Чем меньше CL — тем быстрее память отвечает. Измеряется в тактах, поэтому реальное время зависит от частоты: например, CL16 при 3200 МГц быстрее, чем CL16 при 2400 МГц.

## 5. Тайминги
Тайминги — это набор временных задержек (в тактах), описывающих работу оперативной памяти:  
основные — CL, tRCD (RAS to CAS Delay), tRP (RAS Precharge), tRAS (Active to Precharge).  

## 6. Двухканальный режим
Двухканальный режим — режим работы, при котором два модуля памяти устанавливаются в определённые слоты и работают параллельно, удваивая пропускную способность шины памяти
