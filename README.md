## Схема MAC-адресов

В сети такая обстановка:
|Компьютер   |   MAC-адрес |
|--- |---|
|ПК-1         |  00:1A:2B:3C:4D:01 |
|ПК-2         |  00:1A:2B:3C:4D:02 |
|ПК-3         |  00:1A:2B:3C:4D:03 |
|ПК-4         |  00:1A:2B:3C:4D:04 |
|ПК-5         |  00:1A:2B:3C:4D:05 |
|ПК-6         |  00:1A:2B:3C:4D:06 |

## Возможные ошибки

### 1.Неправильный IP-адрес
MAC-адрес может быть правильным, но компьютеры всё равно не смогут нормально взаимодействовать, если настройки неправильные

Не может должно быть так:
|Пк| IP |
|---|---|
|1| 192.168.1.10|
|2| 192.168.2.1|

Так получается что они в разных подсетях

### Неправильный MAC-адрес
В документации может быть указан неправильный MAC-адрес

Тут нужно через програмные службы узнавать правильный
В Linux к примеру это:
`
ip link
`
