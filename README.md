# Конспект по Процессору

## Типичный микропроцессор
Состоит из: 

* Целочисленная арифметика
* Логические операции

**Регистры** - линейка тригерров, имеющие входы для изменений состояний, котороое влияет на выходы.

**АЛУ** - комбинационная схема, принимающая на два входа два операнда и формирующая на выходе результата
