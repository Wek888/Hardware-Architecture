## 1. Элементы процессора

**Основные компоненты процессора:**
- Дешифратор команд (DC)
- Операционные устройства (АЛУ)
- Устройство управления (УУ)
- Регистры
- Транслятор адресов операндов
- Шины (внутренняя и внешняя)

**Типичный микропроцессор** имеет выводы для адресации, данных, управления шиной, арбитража шины, состояния, прерываний, тактовой частоты и питания (+5 В).

> **Историческая справка.** Первый микропроцессор Intel 4004 (1971 г.) имел вычислительную мощность ENIAC, стоил 200 долларов, содержал 2300 транзисторов, потреблял несколько десятков ватт, тактовая частота — 108 кГц.

- внутренние для специальных целей (регистр адреса памяти, регистр данных);
- внутренние для хранения промежуточных результатов.

## 3. Устройство управления

**Функции УУ:**
- выборка очередной команды из ОЗУ;
- дешифрация кода операции;
- формирование адресов операндов;
- выборка операндов из ОЗУ;
- передача операндов в операционное устройство;
- выполнение операций;
- передача результата в ОЗУ;
- инициирование ввода/вывода;
- реакция на прерывания.

### 3.1. Микропрограммный автомат

**Модель устройства управления:**

**Основные понятия:**
- **Микрооперация** — элементарное действие за один такт.
- **Микрокоманда** — совокупность одновременно выполняемых микроопераций.
- **Микропрограмма** — последовательность микрокоманд, определяющая машинный цикл.

**Состав УУ:**
- управляющая часть: регистр команды, микропрограммный автомат (+ дешифратор команд), узел прерываний и приоритетов;
- адресная часть: операционный узел УУ, регистр адреса, счётчик команд.

### 3.2. Микропрограммный автомат с жёсткой логикой

**Особенности:**
- выходные сигналы управления реализуются однажды соединёнными логическими схемами;
- КОП определяет последовательность сигналов;
- сигналы «привязаны» к импульсам синхронизации;
- счётчик тактов сбрасывается по окончании цикла команды;
- на каждом такте — своя микрокоманда;
- флаги влияют на выработку сигналов.

### 3.3. Микропрограммный автомат с программируемой логикой

**Идея Мориса Уилкса (1951):** между командами и сигналами управления появляется микропрограмма; команда интерпретируется в микропрограмму.

**Особенности:**
- наличие памяти микропрограмм;
- каждой команде соответствует микропрограмма;
- к 70-м годам идея стала преобладающей;
- в современных процессорах от неё отказались из-за сдерживания роста производительности.

## 4. Команды и архитектуры системы команд

**Виды архитектур системы команд:**
- стековая;
- аккумуляторная;
- регистровая;
- с выделенным доступом к памяти.

### 4.1. Стековая архитектура

**Стек** — память по принципу LIFO («последним вошёл, первым вышел»). Операции: `push` и `pop`.

**Обратная польская запись:** знак операции следует за операндами. Пример: `a = a b + a c x +`.

### 4.2. Аккумуляторная архитектура

**Аккумулятор** — регистр для хранения результата и одного из операндов. Команды `load x` и `store x`.

**Достоинства:** короткие команды, простота декодирования.  
**Недостаток:** многократные обращения к памяти.

### 4.3. Регистровая архитектура

**РОН** — регистры общего назначения, явно управляемый кэш. Размер фиксирован, совпадает с машинным словом.

**Подвиды команд:** регистр-регистр, регистр-память, память-память.

**Достоинства:** компактность кода, высокая скорость.  
**Недостаток:** более длинные инструкции.

### 4.4. Архитектура с выделенным доступом к памяти

Обращение к памяти — только через `load` и `store`. Операнды — только в регистрах. Характерна для RISC: Sun SPARC, MIPS R10000, DEC Alpha, PowerPC.
